# YouTube Video Downloader

 A simple terminal-based YouTube video downloader built with Python and yt-dlp.

# Features

 Download YouTube videos
 Save videos as MP4
 Automatic downloads folder creation
 Playlist download prevention
 Download progress display
 Error handling

# Requirements

Python 3
yt-dlp
FFmpeg

# Installation

pip install yt-dlp

# Usage
Run the program:
python main.py

Select an option:
1 - VIDEO DOWNLOADER
2 - EXIT

Enter the YouTube URL when prompted.
Downloaded videos are saved in the downloads folder.


# Technologies

Python
yt-dlp
FFmpeg

# Purpose

This project was created as a Python learning project to practice functions, conditionals, exception handling, dictionaries, file management, external libraries, and download progress hooks.
